# Pomodoro TUI v0.1.0 preview

This prerelease provides a Linux x86_64 binary built and tested on Ubuntu 24.04. It uses a local filesystem for saved state. Other Linux distributions have not been validated with this binary. Windows and macOS are awaiting real-terminal acceptance and are not included in this release.

Download `pomodoro-tui-v0.1.0-x86_64-unknown-linux-gnu.tar.gz` and `SHA256SUMS` into the same directory. Run `sha256sum --check SHA256SUMS`, extract the archive, enter its `pomodoro-tui-v0.1.0-x86_64-unknown-linux-gnu` directory, and run `./pomodoro-tui` in a terminal. Rust is not required to run the binary. See the bundled `README.md` for controls, the saved-state location, backup recovery, and save failure handling.

Linux desktop notifications use `notify-send` when available. Notification failure does not undo a saved session completion. Avoid network and synchronized folders for saved state.
